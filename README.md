SkyBook is a full-stack Flight Booking Management System built using **Spring Boot** and **React**. The application enables users to search flights, book tickets, manage reservations, and handle airline operations through a modern web interface backed by secure REST APIs.

---

# 🚀 Features

### User Features

- User Registration
- Secure Login using JWT Authentication
- Browse Available Flights
- Search Flights
- Book Flight Tickets
- Passenger Management
- View Booking Details
- Ticket Generation
- Payment Processing

### Flight Management

- Add Flights
- Update Flight Details
- Delete Flights
- Aircraft Management
- Flight Scheduling
- Seat Management

### Security

- Spring Security
- JWT Authentication
- Role-Based Authorization
- Protected REST APIs

### Additional Features

- Email Support
- PDF Ticket Generation
- RESTful APIs
- Validation
- Exception Handling

# 🔧 Backend Setup

Clone the repository

```bash
git clone https://github.com/your-username/SkyBook.git
```

Go inside the project

```bash
cd SkyBook
```

Configure your database credentials inside

```
src/main/resources/application.properties
```

Run the backend

```bash
./mvnw spring-boot:run
```

or

```bash
mvn spring-boot:run
```

Backend will start on

```
http://localhost:8080
```

---

# 💻 Frontend Setup

Go to frontend folder

```bash
cd frontend
```

Install dependencies

```bash
npm install
```

Run

```bash
npm run dev
```

Frontend will start on

```
http://localhost:5173
```
